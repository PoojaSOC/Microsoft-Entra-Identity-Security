# Assumptions

## 1. Environment Assumptions

- An authorised Microsoft 365 lab tenant is available.
- Microsoft Entra ID administrative access is available.
- Daniel Silva is a fictional employee joining the Security Operations team as a Cybersecurity Analyst.
- Test identities are fictional and created for learning purposes.
- Internet connectivity is available for Microsoft cloud services.
- The lab tenant supports the required Microsoft 365 services.

## 2. Security Assumptions

- An emergency access account is assumed to be available and must be excluded from applicable Conditional Access policies.
- Administrative actions are performed using authorised accounts.
- Least-privilege principles are followed throughout the implementation.
- Multi-factor authentication is required for Daniel's account.
- Conditional Access policies are tested in report-only mode before enforcement.

## 3. Licensing Assumptions

- Microsoft 365 licensing is available for testing.
- Conditional Access functionality is available within the tenant.
- Group-based licensing is supported or any limitations will be documented.

## 4. Documentation Assumptions

- All screenshots are sanitised before publication.
- No passwords, tenant IDs or sensitive information are published.
- Audit evidence is redacted before upload to GitHub.
- Actual implementation results and limitations are documented accurately.
